# NotebookLM 风格三栏布局重构设计

## 概述

将现有的 DeerFlow Notebook 页面重构为类似 NotebookLM 的三栏布局，提供更直观的资料管理和对话体验。

## 目标

- 实现三栏可调整布局：左(Sources)、中(Chat)、右(Studio)
- 顶部控制栏用于切换面板显示
- 保持现有功能的同时优化用户体验
- 支持响应式设计和移动端适配

## 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│  [TopBar]  📁 Sources 切换    ✨ Studio 切换    [其他操作]   │
├──────────┬───────────────────────────────┬────────────────┤
│          │                               │                │
│  LEFT    │         CENTER                │    RIGHT       │
│  PANEL   │        MAIN AREA              │    PANEL       │
│          │      (Chat Interface)         │   (Studio)     │
│ Sources  │                               │                │

│ History  │                               │                │
│          │                               │                │
├──────────┴───────────────────────────────┴────────────────┤
│                    [Input Box Area]                         │
└─────────────────────────────────────────────────────────────┘
```

## 组件详细设计

### 1. TopBar (顶部控制栏)

**位置**: 固定在顶部
**高度**: 48px
**样式**: 半透明毛玻璃效果 (`bg-background/80 backdrop-blur`)

**内容**:
- 左侧: Logo/返回按钮
- 中部: 两个 Toggle 按钮
  - 📁 **Sources 切换**: 控制左侧面板
  - ✨ **Studio 切换**: 控制右侧面板
- 右侧: 设置、分享等操作

### 2. Left Panel (左侧面板)

**默认宽度**: 280px
**最小宽度**: 200px
**最大宽度**: 400px
**可调整**: 是

**结构**:
1. **笔记本标题区**: 笔记本名称 + 返回列表链接
2. **Tab 切换**:
   - "资料": 上传文件列表 + 上传按钮
   - "历史": 对话历史列表 + 新建对话按钮

### 3. Center Panel (中间主区域)

**自适应宽度**: 占据剩余空间

**内容**:
- 顶部: 对话标题 (可编辑)
- 中部: 消息列表 (Messages)
- 底部: 输入框 (InputBox) + 工具栏

### 4. Right Panel (右侧面板)

**默认宽度**: 320px
**最小宽度**: 240px
**最大宽度**: 480px
**可调整**: 是

**内容**:
- Studio 功能区
- 可以包含: 生成的内容、工具输出、可视化结果等

## 动画与交互

### 面板切换动画
- **过渡时间**: 300ms
- **缓动函数**: `cubic-bezier(0.4, 0, 0.2, 1)`
- **效果**: 宽度变化时内容同步淡入淡出

### Resize 拖拽
- 面板之间可拖拽调整宽度
- 拖拽手柄显示在面板交界处
- 拖拽时有视觉反馈

## 响应式设计

| 断点 | 布局行为 |
|------|----------|
| `≥1280px` | 三栏全开 (默认) |
| `1024px - 1279px` | 左右面板收窄，中间保持最小宽度 |
| `768px - 1023px` | 只保留中间面板，左右可侧滑展开 |
| `<768px` | 单栏布局，顶部有面板切换按钮 |

## 默认状态

- **Sources 面板**: 打开 ✅
- **Studio 面板**: 打开 ✅
- **面板宽度**: 左侧 280px, 右侧 320px
- **记忆用户设置**: 面板状态保存到 localStorage

## 技术实现要点

1. 使用 `react-resizable-panels` 实现可调整面板
2. 使用 `zustand` 或 localStorage 持久化面板状态
3. 使用 CSS Grid 或 Flexbox 实现响应式布局
4. 使用 Framer Motion 或 CSS transitions 实现动画

## 风险与注意事项

1. **现有功能兼容性**: 确保重构后所有现有功能正常工作
2. **性能优化**: 面板切换和resize操作需要流畅
3. **移动端体验**: 小屏幕下的布局需要精心设计
4. **用户习惯**: 现有用户可能需要适应新的布局
