# 惊喜我

通过动态发现可用的技能并创意组合它们来提供意想不到、令人愉快的体验。

## 工作流程

### 步骤 1：发现可用的技能

读取 `<available_skills>` 中列出的所有技能。

### 步骤 2：计划惊喜

选择 **1 到 3** 个技能并设计创意混合。目标是单一内聚的交付物，而非单独的演示。

**创意组合原则：**
- 以意想不到的方式并置技能（例如，关于算法艺术的演示、研究报告变成幻灯片、带有画布设计插图的风格化文档）
- 如果有的话，结合用户已知兴趣/来自记忆的上下文
- 优先视觉冲击和情感愉悦而非信息密度
- 输出应该感觉像一份礼物 — 精致、惊喜且有趣

**主题想法（选择或 remix）：**
- 与今天日期、季节或热门新闻相关的东西
- 用户从未要求但会喜欢的迷你创意项目
- 一个有趣的"如果...会怎样"概念
- 结合数据和设计的美学产物
- 一个有趣的交互式 HTML/React 体验

### 步骤 3：后备方案 — 没有其他技能可用

如果没有发现其他技能（只有 surprise-me 存在），使用这些后备之一：

1. **基于新闻的惊喜**：搜索今天的新闻以寻找一个引人入胜的故事，然后创建一个美观设计的 HTML 产物，以视觉上引人注目的方式呈现它
2. **交互式 HTML 体验**：构建一个创意的单页网络体验 — 生成艺术、一个小游戏、视觉诗、动画信息图或交互式故事
3. **个性化产物**：使用已知的用户上下文创建个人且令人愉快的东西

### 步骤 4：执行

1. 阅读每个选定技能的完整 SKILL.md 正文
2. 按照每个技能的技术执行说明操作
3. 将输出组合成一个内聚的交付物
4. 用最少的铺垫呈现结果 — 让作品自己说话

### 步骤 5：揭示

用最少的剧透呈现惊喜。一句简短的预告线，然后是产物。

- **好的揭示：**"我为你做了一些东西 ✨" + [产物]
- **坏的揭示：**"我决定将 pptx 技能与画布设计技能结合，创建关于...的演示"（破坏了惊喜）
